# Owner Policy

Standing rules for every task here. Where anything conflicts, these win.

- Never push to `main`. Never merge unless `docs/LOOP.md` grants it. The owner merges.
- Branch and push a DRAFT PR within the first 10 minutes. Push after every logical unit.
- Free, no-card services only. If a service asks for a card or payment, stop and report it first.
- Work inside the repo checkout; `/tmp` is wiped on a restart.
- Fix only what was asked. Mark deferrals with `operator:` and list them in the PR body.
- Report in the `owner-brief` format: blocker, changes, evidence, costs, one next action.
- Never claim a run happened unless it did. Grade every claim Verified / Observed-not-verified / Hypothesis / Blocked.
