# Documentation Standards

- Lead with what the reader must do; keep it skimmable.
- A README answers: what is this, how do I run it, how do I test it, how do I deploy it.
- Keep commands copy-pasteable and current; test them.
- Prefer plain, active sentences. Explain the why, not just the what.
- Note anything Blocked or unverified explicitly rather than implying it works.
